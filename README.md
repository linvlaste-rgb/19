# ⚔️ Охотник за головами

Выполнил: Чуланников Данил Юрьевич, группа 25/1, вариант №19.

Программа считает награду за поимку преступника. Чем сложнее и опаснее контракт, тем больше награда. Из неё вычитается налог гильдии.

## 🪙 Возможности

- Расчёт награды с учётом сложности и опасности.
- Вычет налога гильдии.
- Проверка неправильного ввода.

Формула: `Награда = стоимость × сложность × опасность × (1 − налог / 100)`.

## 🛠️ Сборка

```bash
g++ -std=c++17 main.cpp -o main.exe
```

Введите четыре числа через пробел: стоимость, коэффициент сложности, коэффициент опасности и налог в процентах. Дробные числа вводятся через точку.

Стоимость должна быть больше 0, коэффициенты — не меньше 1, налог — от 0 до 100.

## 🎮 Пример

Ввод:

```text
1000 1.5 2 10
```

Результат:

```text
Награда за контракт: 3000.00 золотых монет
Налог гильдии: 300.00 золотых монет
Охотник получает: 2700.00 золотых монет
```
